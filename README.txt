회원별 ERP / 마스터 금액 대조 프로그램

기능
- ERP 엑셀과 마스터 금액 엑셀을 각각 업로드
- 대조 시작 버튼으로 회원등록번호 기준 비교
- 과세 / 면세 / 인보이스를 각각 비교
- 불일치 회원만 별도 Excel 파일로 저장
- ERP 또는 마스터 한쪽에만 존재하는 회원도 불일치로 포함

ERP 집계
- 회원 ID: AL열. 앞에 정확히 'ZZ_'가 있으면 제거
- 금액: AQ열
- 과세/면세 구분: AB열
- 수주유형코드: BG열
- 과세: 801 양수, 811 음수 + AB='과세'
- 면세: 801 양수, 811 음수 + AB='면세'
- 인보이스: 851 양수, 861 음수
- 동일 회원 ID가 여러 행이면 회원별 합산

마스터 집계
- 회원등록번호: G열
- 과세: Q열
- 면세: R열
- 인보이스: S열
- 동일 회원등록번호가 여러 행이면 회원별 합산

비교
- 차액 = ERP 집계액 - 마스터 금액
- 세 항목 중 하나라도 차이가 있으면 불일치
- 한쪽 파일에만 존재하는 회원도 불일치로 표시
- 빈 회원 ID/등록번호 행은 제외
- 헤더 행은 해당 코드가 대상이 아니거나 ID가 비어 있으면 자동 제외
- 원본 파일은 수정하지 않음

EXE 생성
- GitHub 저장소에 member_reconciler.py와 .github/workflows/build-windows.yml을 포함한 전체 파일을 업로드
- Actions에서 'Build Member Amount Reconciler EXE' 실행
- 완료 후 Artifacts에서 '회원별-ERP-마스터-금액대조-EXE' 다운로드
- 최종 사용자 PC에는 Python 설치가 필요 없음

파일 형식
- .xlsx / .xlsm / .xls 지원
- .xls는 xlrd 엔진 사용
